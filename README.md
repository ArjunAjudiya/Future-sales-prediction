\# Future Sales Prediction



\## About Project

Future Sales Prediction is an AI-based project

that predicts future sales using historical sales data.



\## Features

\- Future Sales Prediction

\- Sales Data Analysis

\- Historical Sales Data Processing

\- AI Based Prediction



\## How to Run

1\. Install Python.

2\. Install Jupyter Notebook.

3\. Open future sale prediction.ipynb.

4\. Run the notebook cells.



\## Requirements

\- Python

\- Jupyter Notebook

\- Pandas

\- NumPy

\- Matplotlib
